# CalcIt
simple calculator program for [__"Calc It"__]() programming event, an implementation for shunting yard algorithm.

![CalcIt](./Clacit.jpg)

# Tools Used
This time I used [__meson__](https://mesonbuild.com/) as a build system, to get my self familiar with it, and it appeard to be very easy to use, you can make your way around the 'meson.build' files and see the project structure, it's really a powerfull build system with comperhensive documentation.

# Installation
Just run the __setup.sh__ script, and let it do it's work

you can follow these commands :

```bash

./setup.sh
source /env.sh
```

to run the program just use : 
```bash
CalcIt
```

if you made some changes then you can rebuild the program with :
```bash
./build.sh
```
