# CalcIt
simple calculator program for [__"Calc It"__]() programming event

![CalcIt](./Clacit.jpg)

#Tools Used
This time I used *__meson__* as a build system, though to get my self familiar with it, and it appeard to be very easy to use.

# Installation
Just run the __setup.sh__ script, and let it do it's work

you can follow these commands :

```bash

./setup.sh
source /env.sh
```

to run the program just use : 
```bash
CalcIt
```
